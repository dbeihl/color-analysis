# Contributing

Outside contributions are welcome. Please make your change on a fork and open a pull request from that fork.

Use your own Git identity, with an email address that GitHub links to your account. Your GitHub noreply address works, and so do edits made in GitHub's web editor. On a pull request from your fork, the identity check accepts any commit whose author and committer GitHub links to you as the fork's owner. It holds every other commit to the maintainer's noreply address, which stops the maintainer from publishing a work email here by mistake.
